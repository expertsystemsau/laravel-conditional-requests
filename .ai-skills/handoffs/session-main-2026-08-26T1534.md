## Failed Approaches (Don't Repeat These)

- **Serving the testbed through `lerd`.** `lerd site link` provisioned the vhost and the site
  root returned `200`, but every non-root URI returned `404` from openresty — nginx never
  handed sub-paths to `index.php`. Unlink/relink and `site restart` both failed to fix it;
  other `lerd` sites on the same machine route sub-paths correctly, so it is specific to that
  site, not the tool. Switched to `php artisan serve --port=8391`, which is sufficient for
  everything except the SAPI-specific `Content-Type` check. **If you retry `lerd`, budget for
  debugging its vhost, and do not read the `404`s as a package fault.**

- **Testing write routes registered in `routes/web.php` without excluding CSRF.** Every
  `PATCH`/`PUT`/`DELETE` returned `419` and looked like a package rejection. It is
  `PreventRequestForgery`. Register write routes with
  `->withoutMiddleware([\Illuminate\Foundation\Http\Middleware\PreventRequestForgery::class])`
  or put them in an API route file.

- **Measuring `304` body size with `curl -I … | wc -c`.** `-I` prints headers to stdout, so
  this reports ~1100 bytes and looks like a body leak. Use `curl -o /dev/null -w
  '%{size_download}'`.

- **Gating the wildcard check before stripping the weakness prefix.** An earlier fix stopped
  `If-None-Match: *` short-circuiting but tested the raw candidate, while Symfony strips `W/`
  first — so `W/*` still reached the short-circuit and reopened an unauthenticated existence
  oracle. Fixed by normalising to the strong form *before* the `*` comparison. Do not
  "simplify" `isWildcard()` back.

- **Using `Illuminate\Contracts\Database\ConcurrencyErrorDetector` in the lock path.** It was
  added in laravel/framework **v12.22.0** while `composer.json` advertises `^12.0`, so on
  12.0–12.21 every request through the middleware fatals with `Class ... not found`. Invisible
  locally (only 13.26.1 installed). Replaced with the long-standing
  `Illuminate\Database\DetectsConcurrencyErrors` trait. **Before adding any framework symbol,
  check which release introduced it.**

- **Asserting `assertHeaderMissing('ETag')` as proof a write guard passed through.** It is
  satisfied equally by `200`, `412`, `428` and `500`. Use a controller-execution counter and
  re-read the record.

## Key Decisions

| Decision | Rationale |
|---|---|
| Phases resequenced: model validators before the write path | The write path must know the resource's current validator *before* the controller runs; a body hash cannot supply one because there is no response yet. The original spec order was not buildable. |
| `fromRequest()` on a sub-interface, not on `ValidatorStrategy` | Widening the base contract would break every custom strategy and falsely imply any strategy can answer pre-controller. |
| Model-derived validators are **strong** | RFC 9110 §13.1.1 requires strong comparison for `If-Match`; a weak tag would reject every guarded write forever. |
| Do not short-circuit a bare `If-None-Match: *` or a lone `If-Modified-Since` | Both are obtainable with zero prior knowledge and produced an unauthenticated existence/timestamp oracle behind gates that never ran. Compute saving deliberately surrendered. |
| `If-Match: *` **is** honoured (opposite of the read path) | On `If-Match` the wildcard is a legitimate "any current representation" precondition. Same token, different header, opposite handling. |
| `required` satisfied only by `If-Match`, `If-None-Match: *`, or a valid `If-Unmodified-Since` | A concrete `If-None-Match` provided no lost-update protection and let a client bypass the guard with any garbage value. |
| Fingerprint includes database name and table prefix | Bare `getTable()` made tenant A's and tenant B's records share an ETag — a cross-tenant content leak. Single-database row-level tenancy still needs the documented override. |
| `targetExists()` has **no default** | `false` would reinstate a fail-open; `null` would refuse every legitimate create. A v0.2 custom strategy fatals loudly instead of silently passing writes. |
| Facade deleted before the freeze | Its entire real surface was one boot-time `extend()` call, and a facade makes that call easy from exactly the places the docs forbid. |
| `lock` is opt-in, never implicit | Forcing a transaction on every guarded write is surprising and costly. |

## Code Context

```php
// Middleware, order-independent flags. `required`/`lock` imply the `model` strategy.
Route::get('/articles/{article}', ShowArticle::class)->middleware('conditional');
Route::get('/articles/{article}', ShowArticle::class)->middleware('conditional:model');
Route::patch('/articles/{article}', UpdateArticle::class)->middleware('conditional:required');
Route::patch('/articles/{article}', UpdateArticle::class)->middleware('conditional:required,lock');

// Model side
class Article extends Model implements ProvidesConditionalValidator
{
    use HasConditionalValidator;   // strong xxh128 over database \0 prefix \0 table \0 key \0 version
}

// Config keys (config/laravel-conditional-requests.php)
// enabled, strategy, hash, weak, last_modified, max_response_bytes, methods, exclude, lock_timeout

// Custom strategies — there is NO facade; inject the registry
public function boot(ConditionalRequests $conditional): void

    $conditional->extend('revision', fn (): ValidatorStrategy => new RevisionStrategy);
}
```

## Edge Cases & Error Handling

- **Handled:** blank and zero-member precondition headers; malformed HTTP-dates (strict
  three-format parsing, not `strtotime`); `W/*` per-header asymmetry; streamed, binary,
  oversized, pre-tagged and non-2xx responses; unresolved routes under global placement;
  ambiguous multi-model write routes; lock timeouts → `503` with `Retry-After`.
- **Deferred, documented:** `If-None-Match: *` cannot distinguish "absent" from "exists but
  unversioned" on strategies that do not implement `targetExists()` precisely; single-database
  row-level tenancy still needs a `conditionalValidator()` override; the create guard is not
  atomic without `lock`.

## Warnings

- **The 5 skipped tests are not a defect.** SQLite's `compileLock()` returns an empty string,
  so `lockForUpdate()` emits no SQL at all — mutual exclusion is unprovable there by any
  arrangement. `tests/Feature/LostUpdateTest.php` deliberately asserts the harness *cannot*
  see a row lock, so the file cannot be mistaken for a complete proof. Do not delete it.
- **The short-circuit skips everything the controller would have decided,** including
  per-record authorization. Place `conditional` **after** anything that can reject the
  request. `docs/hazards.md#h1`.
- **`terminate()` still runs on a short-circuited request even though `handle()` did not.**
  A request timer will compute against `null`. `docs/hazards.md#h2`.
- **A `version` column that does not change on every write freezes the tag permanently** —
  `304` forever against stale content. `docs/hazards.md#h3`.
- **`Content-Type` on a `304` differs by SAPI.** Under kernel-global placement the middleware
  prepares the response itself so PHP's `default_mimetype` is suppressed; this was reproduced
  and fixed on the CLI SAPI only and never verified on php-fpm. Step 8 exists for that.
- **PHP 8.3 is the floor and cannot be checked locally.** Write `(new Foo)->bar()`, never
  `new Foo()->bar()`. CI's `prefer-lowest` leg is the only real guard.
- **`HasConditionalValidator` has zero type-coverage signal** — the Pest plugin filters out any
  file containing the string `trait ` before analysis. PHPStan level 7 still covers it.
