# v0.1 Read Path Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship the conditional read path — attach an `ETag` to eligible responses and return `304 Not Modified` when the client's `If-None-Match` matches.

**Architecture:** One route middleware runs after the controller, asks a swappable strategy for a validator, sets it on the response with Symfony's `setEtag()`, then calls Symfony's `isNotModified()`, which performs the RFC-correct comparison and mutates the response into a compliant 304. We write the validator generation and the eligibility rules; Symfony owns the comparison.

**Tech Stack:** PHP 8.3–8.5, Laravel 12–13, Pest 4/5, Orchestra Testbench, PHPStan level 7, Pint.

**Spec:** `docs/design/2026-08-25-conditional-requests-design.md`

## Global Constraints

- PHP `^8.3`; Laravel `^12.0||^13.0`. Do not add runtime dependencies.
- Every `src/` file starts with `declare(strict_types=1);` — enforced by `tests/ArchTest.php`.
- `dd()`, `ddd()`, `env()`, and `exit()` are banned everywhere, config files included — enforced by `tests/ArchTest.php`.
- Config key namespace and publish tags stay `laravel-conditional-requests*`.
- Root namespace is `ExpertSystems\ConditionalRequests\`.
- Type coverage gate is 100% (`composer test:types`). Annotate array shapes; PHPStan runs at level 7 over `src` and `config`.
- Commit subjects match the existing history style — sentence case, imperative, no `feat:`/`fix:` prefixes.
- Scope is the read path only. No `If-Match`, `412`, `428`, `Last-Modified`, model-derived validators, or locking — those are v0.2–v0.5.

```php
<?php

declare(strict_types=1);

namespace ExpertSystems\ConditionalRequests\Validators;

/**
 * An HTTP validator: the opaque token identifying one version of a resource.
 */
final readonly class Validator
{
    /**
     * The entity tag, stored bare — no surrounding quotes, no weakness prefix.
     */
    public string $etag;

    public function __construct(string $etag, public bool $weak = false)
    {
        $this->etag = self::normalize($etag);
    }

    /**
     * The tag as it appears on the wire.
     */
    public function header(): string
    {
        return ($this->weak ? 'W/' : '').'"'.$this->etag.'"';
    }

    /**
     * Accept a bare, quoted, or weak-prefixed tag and reduce it to the bare form.
     */
    private static function normalize(string $etag): string
    {
        $etag = trim($etag);

        if (str_starts_with($etag, 'W/')) {
            $etag = substr($etag, 2);
        }

        return trim($etag, '"');
    }
}
```

```php
<?php

declare(strict_types=1);

namespace ExpertSystems\ConditionalRequests\Validators;

use ExpertSystems\ConditionalRequests\Contracts\ValidatorStrategy;
use Illuminate\Http\Request;
use Symfony\Component\HttpFoundation\Response;

/**
 * Derives a validator by hashing the rendered response body.
 *
 * Works on any route with no setup, at the cost of running the controller
 * before the validator is known — this strategy saves bandwidth, not compute.
 */
final readonly class BodyHashStrategy implements ValidatorStrategy
{
    public function __construct(
        private string $algorithm = 'xxh128',
        private bool $weak = false,
    ) {}

    public function fromResponse(Request $request, Response $response): ?Validator
    {
        $content = $response->getContent();

        if ($content === false || $content === '') {
            return null;
        }

        return new Validator(hash($this->algorithm, $content), $this->weak);
    }
}
```

```php
declare(strict_types=1);

namespace ExpertSystems\ConditionalRequests;

use Closure;
use ExpertSystems\ConditionalRequests\Contracts\ValidatorStrategy;
use InvalidArgumentException;

/**
 * Registry of the validator strategies available to the middleware.
 */
final class ConditionalRequests
{
    /**
     * @var array<string, Closure(): ValidatorStrategy>
     */
    private array $strategies = [];

    /**
     * Register a strategy under a name usable as a middleware flag.
     *
     * @param  Closure(): ValidatorStrategy  $resolver
     */
    public function extend(string $name, Closure $resolver): void
    {
        $this->strategies[$name] = $resolver;
    }

    /**
     * Resolve a registered strategy.
     *
     * @throws InvalidArgumentException when no strategy is registered under the name
     */
    public function strategy(string $name): ValidatorStrategy
    {
        $resolver = $this->strategies[$name] ?? null;

        if (! $resolver instanceof Closure) {
            throw new InvalidArgumentException(
                "Conditional request strategy [{$name}] is not registered."
            );
        }

        return $resolver();
    }
}
```

```php
<?php

declare(strict_types=1);

namespace ExpertSystems\ConditionalRequests\Http\Middleware;

use Closure;
use ExpertSystems\ConditionalRequests\ConditionalRequests;
use ExpertSystems\ConditionalRequests\Validators\Validator;
use Illuminate\Contracts\Config\Repository;
use Illuminate\Http\Request;
use Symfony\Component\HttpFoundation\Response;

/**
 * Handles RFC 9110 conditional requests for a route.
 */
final readonly class Conditional
{
    public function __construct(
        private ConditionalRequests $registry,
        private Repository $config,
    ) {}

    /**
     * @param  Closure(Request): Response  $next
     */
    public function handle(Request $request, Closure $next, string ...$flags): Response
    {
        $response = $next($request);

        $validator = $this->registry
            ->strategy($this->strategyName($flags))
            ->fromResponse($request, $response);

        if (! $validator instanceof Validator) {
            return $response;
        }

        $response->setEtag($validator->etag, $validator->weak);

        return $response;
    }

    /**
     * The first flag naming a strategy wins; otherwise fall back to config.
     *
     * @param  list<string>  $flags
     */
    private function strategyName(array $flags): string
    {
        foreach ($flags as $flag) {
            if ($flag !== '') {
                return $flag;
            }
        }

        return (string) $this->config->get('laravel-conditional-requests.strategy', 'body');
    }
}
```

```php
    /**
     * Whether this request and response should take part in the read path.
     */
    private function eligible(Request $request, Response $response): bool
    {
        if ($this->config->get('laravel-conditional-requests.enabled', true) !== true) {
            return false;
        }

        if ($response instanceof StreamedResponse || $response instanceof BinaryFileResponse) {
            return false;
        }

        if (! $response->isSuccessful() || $response->getEtag() !== null) {
            return false;
        }

        if (! in_array($request->getMethod(), $this->methods(), strict: true)) {
            return false;
        }

        if ($this->excluded($request)) {
            return false;
        }

        $content = $response->getContent();

        if ($content === false) {
            return false;
        }

        $ceiling = (int) $this->config->get('laravel-conditional-requests.max_response_bytes', 1_048_576);

        return $ceiling <= 0 || strlen($content) <= $ceiling;
    }

    /**
     * @return list<string>
     */
    private function methods(): array
    {
        /** @var list<string> $methods */
        $methods = $this->config->get('laravel-conditional-requests.methods', ['GET', 'HEAD']);

        return array_map(strtoupper(...), $methods);
    }

    /**
     * Match the request against the configured route-name and URI exclusions.
     */
    private function excluded(Request $request): bool
    {
        /** @var list<string> $patterns */
        $patterns = $this->config->get('laravel-conditional-requests.exclude', []);

        if ($patterns === []) {
            return false;
        }

        return $request->routeIs(...$patterns) || $request->is(...$patterns);
    }
```

A ceiling of zero or less disables the size check, which is the natural reading of "no limit".

### Task 8: HEAD parity

A `HEAD` request must produce the same validator as the equivalent `GET`, or a client that probes with `HEAD` gets a tag it can never match.

This was expected to pass without production changes, on the assumption that `Router::runRoute()` calls `prepareResponse()` *after* the route middleware stack unwinds. That assumption was incomplete rather than false: **both** calls fire, and they explain different things.

- `Router.php:799` — the outer call, in `runRoute()`, wrapping the whole middleware stack. It runs last, with the request method already restored to `HEAD`, which is why Symfony's `Response::prepare()` nulls the body again on the way out and the middleware's own nulling is redundant under route or group placement.
- `Router.php:821` — the inner call, the pipeline destination inside `runRouteWithinStack()`. It runs *before* control returns to any route middleware's post-`$next()` code, and `Response::prepare()` nulls the body for `HEAD` there. That is why the fix was necessary at all: by the time `Conditional::handle()` first inspects the response, there is nothing left to hash.

The middleware's nulling is therefore load-bearing only under **global** placement, where the method is still `GET` for both calls and nothing downstream re-prepares the response.

The fix required a production change: mutate the request method to `GET` around `$next($request)`, restore it afterward, and re-empty the response body once the validator is attached — the werk365 mutate-and-restore approach the original plan asked us to avoid without a failing test demanding it. That test now exists (`HeadRequestTest.php`), and the fix landed in `Conditional::handle()`.
